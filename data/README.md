# Data Instructions

The original raw dataset is not included in this repository because of its large size.

The full dataset is approximately 16 GB, which is too large for normal GitHub storage. Therefore, this repository only contains the analysis code, generated report outputs, and instructions for placing the dataset locally.

## How to Add the Data Locally

To reproduce the analysis, download and extract the original dataset on your computer.

Then place the extracted folders inside:

```text
data/raw/
```

The expected local folder structure is:

```text
data/raw/
├── Input/
├── LogFiles/
├── LogFilesProductWarmupFilter/
├── Output/
├── OutputWarmupFilter/
└── experimentResults.xlsx
```

## Files Used in This Project

The main files used by the analysis scripts are:

```text
data/raw/LogFilesProductWarmupFilter/Exp{experiment}Run{run}.txt
data/raw/OutputWarmupFilter/Exp{experiment}Run{run}.txt
data/raw/OutputWarmupFilter/DisposedProducts{experiment}Run{run}.txt
```

The selected experiments are:

```text
Experiment 10
Experiment 14
Experiment 23
```

For each selected experiment, runs 1 to 20 are used.

## Event Log Columns

The main event log columns used for process mining are:

```text
productIDStr       case identifier
event              activity name
timeStamp          timestamp
vehicle            resource identifier
vehicleType        vehicle/resource type
currentDecayLevel  quality decay attribute
processingStation  station attribute
```

## Case, Activity, and Timestamp

The process mining setup is:

```text
Case ID:    productIDStr
Activity:   event
Timestamp:  timeStamp
```

During preprocessing, experiment and run identifiers are added to create unique case identifiers across multiple logs.

## Generated Data

Some intermediate files are generated when running the scripts. These are intentionally not tracked in Git because they are large or reproducible.

Examples:

```text
data/processed/
outputs/xes/
outputs/tables/selected_output_combined.csv
```

These files can be regenerated by running the scripts after placing the raw dataset in `data/raw/`.

## Reproducibility

After the raw data is placed in the correct folder, the full analysis can be reproduced by running the scripts from the main project `README.md` in the specified order.
